# 多平台媒体解析与微信自动发送助手 · 可视化管理面板

集成 **抖音 / 哔哩哔哩 / 小红书 / 网易云音乐 / QQ音乐 / 电子书** 自动解析、检索、下载与微信自动转发的一体化本地 Web 管理系统。

---

## 🌟 核心特性

- **多平台媒体与卡片解析**
  - 🎬 **抖音 (Douyin)**：支持短链、视频、图文笔记；采用内置游客态凭证自动获取机制（免提供 Cookie），支持高清无水印视频与图集下载。
  - 📺 **哔哩哔哩 (Bilibili)**：支持 BV/av 号、b23.tv 短链、番剧/影视链接；内置 `yutto` + `ffmpeg` 高清音视频混流，画质可配置（360P 至 1080P），支持配置 SESSDATA 获取更高画质。
  - 📕 **小红书 (Xiaohongshu)**：支持普通链接与分享短链；支持图文多图、视频提取，内置 XHS-Downloader 引擎，支持配置 Cookie 获取高分辨率资源。
  - 🎵 **网易云音乐 (NetEase)**：支持单曲长短链及微信小程序/音乐卡片解析；采用 API 优先 + yt-dlp 兜底双引擎，支持标准至无损多档音质切换。
  - 🎶 **QQ 音乐 (QQ Music)**：支持单曲链接与卡片解析；支持网页 Cookie 配置与音频提取。
  - 📚 **电子书检索与下载**：支持微信消息指令触发（默认指令 `./下载 书名`，前缀支持自定义）；自动多源搜索、极速下载并自动转换为标准 UTF-8 `.txt` 电子书文件推送。

- **微信自动化发送与智能调度**
  - ⚡ **双重监听架构**：WeFlow 主动推送（SSE 毫秒级实时响应） + 会话轮询兜底（覆盖自发消息与漏推）。
  - 🛡️ **安全过滤机制**：私聊直接处理，群聊需配置白名单放行；支持一键开启「测试模式」（所有内容转发至文件传输助手）。
  - 💬 **引用回复与去重**：发送媒体文件时自动引用对方原消息/分享卡片；基于消息 `rawid` 全局去重，彻底杜绝重复下载与发送。
  - 🧹 **存储自动清理**：支持发送后延迟自动删除临时视频/音频文件（默认 180 秒），保障本地磁盘空间。

- **现代化 Web 可视化管理面板**
  - 📊 **Dashboard 仪表盘**：实时展示微信/WeFlow/各平台解析引擎/监听状态；今日任务成功/失败统计；一键启动/停止监听与连接连通性自检。
  - ⚙️ **可视化配置中心**：全平台参数图形化配置，支持视口居中目录选择器，Token/密钥自动脱敏保护。
  - 📋 **任务记录与运行日志**：详尽记录任务来源、处理耗时、链接与状态；环形内存缓冲实时日志流，支持错误高亮与清空。

## 🚀 快速开始

### 方式 A：直接运行打包版（推荐）

1. 双击运行 `dist\抖音视频自动发送\抖音视频自动发送.exe`（或使用项目自带的启动脚本）。
2. 程序启动后自动开启本地服务并打开浏览器，进入管理面板。
3. 依次配置：**WeFlow** → **微信** → **测试连接** → **启动监听**。

> 💡 注意：整个 `dist\抖音视频自动发送\` 文件夹需完整保留（EXE 依赖同级 `_internal` 依赖资源）。

### 方式 B：开发环境运行（Python 3.10+）

```bash
# 1. 启动管理面板（自动打开浏览器）
启动自动发送.cmd

# 或通过命令行启动
python app.py
```

## 📖 使用步骤

| 步骤 | 模块 | 操作说明 |
|:---:|:---|:---|
| **①** | **WeFlow** | 进入「配置中心 → WeFlow」：填写 Base URL 与 API Token，点击「测试连接」确保连通。 |
| **②** | **解析引擎** | 各平台按需开启；抖音内置游客态免 Cookie；B站/小红书/网易云/QQ音乐可按需填入 Cookie 以获取更高画质/音质。 |
| **③** | **电子书** | 进入「配置中心 → 电子书」：开启开关，设定触发指令前缀（默认 `./下载`）。 |
| **④** | **微信配置** | 进入「配置中心 → 微信」：配置群聊白名单或开启测试模式；确保电脑端微信已登录运行。 |
| **⑤** | **启动服务** | 返回「Dashboard」页面，点击「启动监听」即可开始自动化监听与转发。 |

│   ├── logger.py               # 环形日志缓存与敏感信息脱敏过滤器
│   ├── state.py                # 运行状态与组件健康检测
│   └── tasks.py                # 任务记录追踪与统计
├── web/                        # Web 管理面板前端
│   ├── server.py               # 原生 HTTP API 服务端
│   └── static/                 # 前端静态单页应用（HTML / CSS / JavaScript）
├── tools/                      # 内置工具集
│   ├── ffmpeg/                 # ffmpeg 音视频混流工具
│   └── xhs/                    # 小红书底层下载引擎
├── config/
│   ├── config.example.json     # 配置模板（安全公开版本，不含敏感 Token）
│   └── config.json             # 运行时本地配置（已被 .gitignore 忽略）

├── logs/                       # 系统日志输出目录
├── videos/                     # 临时媒体下载目录（支持发送后定时自动清理）
├── douyin_sender.spec          # PyInstaller 打包配置
├── 启动自动发送.cmd             # Windows 启动脚本
├── 启动微信_QT无障碍.cmd        # 辅助启动脚本
└── 打包EXE.cmd                  # 一键打包脚本

## 🛠️ 打包 EXE

项目支持使用 PyInstaller 打包为免 Python 环境的绿色分发包：

```bash
# 安装 PyInstaller
pip install pyinstaller

# 执行打包
pyinstaller douyin_sender.spec --noconfirm --clean
# 或直接双击运行
打包EXE.cmd
```

打包产物位于 `dist\抖音视频自动发送\` 目录中。

## 🔌 外部依赖说明

- **微信客户端**：需在 Windows 上安装并登录微信 PC 版（`Weixin.exe`），消息发送由 `wxauto4` 底层驱动。
- **WeFlow**：需在本地运行 WeFlow（默认端口 `5031`），并在「设置 → API 服务」中启用「主动推送」与 API 服务。
- **FFmpeg / yutto**：项目内置或支持系统环境变量自动探测，用于 B站等高分辨率音视频混流。

---

## 🔒 安全与隐私声明

1. **本地绑定**：Web 服务默认仅监听 `127.0.0.1` 本地回环地址，不对外网暴露端口。
2. **凭据脱敏**：WeFlow Token、第三方 Cookie 等敏感配置在 API 返回及前端展示时均经过脱敏保护，日志中自动屏蔽敏感字符。
3. **隔离安全**：用户的真实凭证与运行时数据（`config/config.json`、`douyin_cookie.txt`、`data/`、`logs/` 等）均已加入 `.gitignore`，不会提交至公开代码仓库。
