关于本系统

媒体自动化发送助手 (Media Auto Sender) 是一套专为微信生态打造的本地化多媒体链接智能解析与群聊/私聊自动转发中枢。

支持抖音无水印原片、B站高清视频、小红书精美图文、网易云与QQ音乐高保真音频。

本地安全与隐私保障：
本系统默认仅在本地回环网络 127.0.0.1 监听，所有数据均保留在您的电脑本地，敏感 Token 脱敏存储，绝不上报云端。
快速上手工作流
  • 1. 启动 WeFlow 与微信：确保微信 PC 客户端与 WeFlow 正常运行。
  • 2. 配置平台参数：在「配置中心」测试 WeFlow 连通性。
  • 3. 开启实时监听：在 Dashboard 点击「启动监听」，在微信发送抖音/B站/小红书链接即可体验自动解析与发送！
依赖环境状态
  • ✅ 微信 (WeChat)：已连接 Windows UI 自动化接口
  • ✅ 抖音解析：内置全自动游客态 Cookie 算法
