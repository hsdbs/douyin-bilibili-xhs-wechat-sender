关于

视频自动发送 v1.0.0
自动监听微信消息中的链接，解析抖音 / B站 / 小红书 视频与图文并发送给对应联系人的本地工具。

使用步骤
  • ① 配置 WeFlow 地址与 Token，点击「测试连接」（使用主动推送需在 WeFlow 开启「主动推送」）
  • ② 确认微信已登录并运行
  • ③ 回到 Dashboard，点击「启动监听」
外部依赖
  • ✅ 微信（Weixin.exe）需已登录并保持运行
  • ✅ WeFlow 服务需已启动（主动推送监听需额外开启「主动推送」，轮询监听无需）
  • ✅ 抖音解析自动获取游客态 Cookie（无需手动填写）
  • ✅ B站解析依赖 yutto + FFmpeg（详见配置中心）
  • ✅ 小红书解析基于 XHS-Downloader（已内置，Cookie 可选）
数据安全

本服务仅监听 127.0.0.1，不对外网开放。
WeFlow Token 等敏感信息默认隐藏、脱敏返回、不写入普通日志。
